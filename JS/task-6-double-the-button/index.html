Double Button

Click a button to remove it and create two new buttons.

⚡ Click to multiply
🔄 Infinite generation
Every new button has the same behavior.

🧠 How it works

I have a function that gives one button the ability to double itself.

When the button is clicked, it is removed and two new buttons are created.

Each new button is then passed back into doubleButton(newButton), which gives the new button the same click behavior.

Click button → Remove it → Create 2 → Give them behavior
Every new button has the same behavior.
